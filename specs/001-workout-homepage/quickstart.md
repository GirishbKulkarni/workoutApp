# Quickstart: Workout Homepage

## Prerequisites
- Node.js v18+
- npm or yarn

## Setup Instructions

1. **Navigate to the frontend directory**:
   ```bash
   cd frontend
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Access the application**:
   Open your browser and navigate to `http://localhost:5173` (or the port Vite provides).

## Mock Data Loading

The application uses local JSON for its state initially. The mock data is located at `frontend/src/data/mockData.json`. Any changes to attendance will be persisted in your browser's `localStorage` to simulate a database.
